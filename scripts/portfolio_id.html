Pipeline MLOps yang mengotomatisasi proses retraining model machine learning menggunakan MLflow Project dan GitHub Actions CI. Menggunakan dataset Breast Cancer Wisconsin untuk proof-of-concept, dengan deployment Docker Hub untuk reproducibility lingkungan.
Python MLflow GitHub Actions Docker Conda scikit-learn
▸MLflow Project Spec: file MLproject terstandar untuk reproducibility model training
▸CI/CD Pipeline: GitHub Actions workflow otomatis menjalankan mlflow run MLProject --env-manager=local

▸Docker Hub Integration: image dipublikasikan untuk deployment ke environment lain
